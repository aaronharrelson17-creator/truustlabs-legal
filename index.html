TRUUST Labs Content Automation — Privacy Policy

Last updated: October 14, 2026

TRUUST Labs Content Automation is an internal tool being developed by TRUUST Labs to manage its own Pinterest content and reporting. The Pinterest integration is not currently active.

Information accessed

If authorized, the tool may access the connected TRUUST Labs Pinterest account's profile identifiers, boards, Pins, publishing results, and performance analytics as permitted by Pinterest API scopes. It is not designed to access unrelated users' private accounts.

How information is used

Account information will be used to prepare, review, schedule, and publish approved TRUUST Labs content; prevent duplicate publication; and produce internal performance reports.

Storage and security

Development scripts run through GitHub Actions. Once enabled, API credentials will be stored in restricted GitHub Actions secrets, not source code. Reports should avoid personal information. Logs may contain limited operational metadata. Access is limited to authorized administrators and applicable service providers.

Sharing

Information is not sold. Data may be processed by services needed to operate the integration, including GitHub and Pinterest, subject to their own terms and privacy policies. The tool is not currently offered to external customers.

Retention and deletion

Operational records will be retained only as needed for automation, troubleshooting, and security, and deleted when no longer needed. Authorization can be revoked in the Pinterest account's connected-app settings. Following revocation, future API access stops; existing operational records can be requested for deletion using the contact below.

Contact

Changes

This policy may be updated as the tool's features or data practices change. The latest version and effective date will be posted here.

This policy covers the TRUUST Labs Content Automation app, not Payhip's separate payment processing or the full Payhip storefront.
